# The old app (archived 2026-11-12)

The pages Reflect had before the new design: the journal, ideas, Me, legacy, and the old Learn pages
(book page, uploads, courses, credentials, the memory sweep, the old browse page), with their e2e tests.
Torian asked on 2026-11-12 to separate them from the new design and archive them, since the two clashed.

Nothing here is routed, built or type-checked. It is kept, not deleted, so any part can come back into the
new design. The server stores these pages used stay in `web/src/server/`, since the MCP tools still use
them.
